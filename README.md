## 🛠️ Tech Stack & Implementation

* **Markup:** Semantic HTML5 with Open Graph & Twitter Card metadata.
* **Styling:** Custom CSS3 with glassmorphism (`backdrop-filter`), CSS Grid/Flexbox, radial glowing borders, and CSS custom properties.
* **Typography:** Preloaded web fonts (`Gloock` serif for headings and `Manrope` sans-serif for UI elements).
* **Performance & Accessibility:** Zero JS overhead, full keyboard focus rings, WCAG AA contrast compliance, and `prefers-reduced-motion` support.
* **Hosting:** GitHub Pages.
